# Formation Data Analyst (OpenClassrooms)
Ce dépôt contient les projets réalisés dans le cadre du parcours de formation Data Analyst dispensé par [OpenClassrooms](https://openclassrooms.com/fr/paths/804-data-analyst).

## 📑 Projets réalisés
Le scénario, les objectifs, les outils utilisés et les compétences acquises sont détaillés pour chacun des projets dans le répertoire qui lui est dédié.

* [Projet 1 : Prenez en main votre formation de Data Analyst](./P01 Prenez en main votre formation de Data Analyst/)<br>
Premier projet du parcours, consacré à la prise en main de la formation et à la définition du cadre de travail.
* [Projet 2 : Faites une analyse de ventes pour un e-commerce (Excel)](./projets/projet-3/)<br>
Analyser les ventes d'un e-commerce sur Excel et restituer les résultats sous forme de visualisations et d'un storytelling structuré.
* [Projet 3 : Requêtez une base de données (SQL)](./projets/projet-3/)<br>
Projet d'entraînement aux fondamentaux du SQL et de la gestion de bases de données, sur un jeu de données issu du secteur des assurances.
* [Projet 4 : Réaliser une étude de santé publique (Python)](./projets/projet-4/)<br>
Manipulation de *DataFrame*, préparation de données, analyse exploratoire, analyse de données.
* [Projet 5 : Créez et utilisez une base de données immobilière (SQL)](./projets/projet-3/)<br>
Conception et exploitation d'une base de données immobilière complète, en respectant les règles de modélisation relationnelle (3NF) et les exigences du RGPD.
* [Projet 6 : Optimiser la gestion des données d'une boutique (Python)](./projets/projet-5/)<br>
Préparation de données, analyse exploratoire, analyse univariée.
* [Projet 7 : Créez un tableau de bord dynamique pour visualiser l'avancement de projets (Power BI)](./projets/projet-6/)<br>
Création d'un tableau de bord dynamique pour visualiser l'avancement de projets clients, de la collecte du besoin à la livraison.
* [Projet 8 : Analysez des indicateurs de l'égalité femme-homme (Knime)](./projets/projet-7/)<br>
Création d'un rapport automatique dans un ETL (importation, nettoyage, visualisation et exportation).
* [Projet 9 : Analyser les ventes d'une librairie (Python)](./projets/projet-6/)<br>
Préparation de données, analyse exploratoire, analyse descriptive et tests statistiques.
* [Projet 10 : Faites une étude sur l'eau potable (Power BI)](./projets/projet-6/)<br>
Conception d'un tableau de bord interactif pour analyser l'accès à l'eau potable à l'échelle mondiale et orienter les décisions stratégiques.
* [Projet 11 : Produisez une étude de marché avec Python](./projets/projet-9/)<br>
Analyse exploratoire, analyse descriptive, *clustering*.
* [Projet 12 : Détectez des faux billets avec Python](./projets/projet-10/)<br>
Analyse exploratoire, analyse descriptive, algorithme de prédiction.
