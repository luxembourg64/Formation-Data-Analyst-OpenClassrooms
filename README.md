# Formation Data Analyst (OpenClassrooms)
Ce dépôt contient les projets réalisés dans le cadre du parcours de formation Data Analyst dispensé par [OpenClassrooms](https://openclassrooms.com/fr/paths/804-data-analyst).

## 📑 Projets réalisés
Le scénario, les objectifs, les outils utilisés et les compétences acquises sont détaillés pour chacun des projets dans le répertoire qui lui est dédié.

* [Projet 1 : Prenez en main votre formation de Data Analyst](./P01%20Prenez%20en%20main%20votre%20formation%20de%20Data%20Analyst/)<br>
Premier projet du parcours, consacré à la prise en main de la formation et à la définition du cadre de travail.
* [Projet 2 : Faites une analyse de ventes pour un e-commerce (Excel)](./P02-Faites%20une%20analyse%20de%20ventes%20pour%20un%20e-commerce%20(excel)/)<br>
Analyser les ventes d'un e-commerce sur Excel et restituer les résultats sous forme de visualisations et d'un storytelling structuré.
* [Projet 3 : Requêtez une base de données (SQL)](./P03-requ%C3%AAtes%20SQL%20(BDD%20assurances)/)<br>
Projet d'entraînement aux fondamentaux du SQL et de la gestion de bases de données, sur un jeu de données issu du secteur des assurances.
* [Projet 4 : Réaliser une étude de santé publique (Python)](./P04-R%C3%A9alisez%20une%20%C3%A9tude%20de%20sant%C3%A9%20publique%20-%20FAO%20(Python)/)<br>
Manipulation de *DataFrame*, préparation de données, analyse exploratoire, analyse de données.
* [Projet 5 : Créez et utilisez une base de données immobilière (SQL)](./P05-Base%20de%20donn%C3%A9es%20immobili%C3%A8re%20(SQL)/)<br>
Conception et exploitation d'une base de données immobilière complète, en respectant les règles de modélisation relationnelle (3NF) et les exigences du RGPD.
* [Projet 6 : Optimiser la gestion des données d'une boutique (Python)](./P06-Gestion%20des%20donn%C3%A9es%20boutique%20(Python)/)<br>
Préparation de données, analyse exploratoire, analyse univariée.
* [Projet 7 : Créez un tableau de bord dynamique pour visualiser l'avancement de projets (Power BI)](./P07-Dashboard%20suivi%20de%20projets%20(Power%20BI)/)<br>
Création d'un tableau de bord dynamique pour visualiser l'avancement de projets clients, de la collecte du besoin à la livraison.
* [Projet 8 : Analysez des indicateurs de l'égalité femme-homme (Knime)](./P08-%C3%A9galit%C3%A9%20F-H%20et%20RGPD%20(KNIME)/)<br>
Création d'un rapport automatique dans un ETL (importation, nettoyage, visualisation et exportation).
* [Projet 9 : Analyser les ventes d'une librairie (Python)](./P09-Analysez%20des%20ventes%20librairie%20(Python)/)<br>
Préparation de données, analyse exploratoire, analyse descriptive et tests statistiques.
* [Projet 10 : Faites une étude sur l'eau potable (Power BI)](./P10-%C3%A9tude%20acc%C3%A8s%20eau%20potable%20(Power%20BI)/)<br>
Conception d'un tableau de bord interactif pour analyser l'accès à l'eau potable à l'échelle mondiale et orienter les décisions stratégiques.
* [Projet 11 : Produisez une étude de marché avec Python](./P11-%C3%A9tude%20de%20march%C3%A9%20internationale%20(Python)/)<br>
Analyse exploratoire, analyse descriptive, *clustering*.
* [Projet 12 : Détectez des faux billets avec Python](./P12-D%C3%A9tection%20faux%20billets%20(Python%20-%20ML)/)<br>
Analyse exploratoire, analyse descriptive, algorithme de prédiction.
* [Projet 13 : Portfolio professionnel de la data](./P13-portfolio%20professionnel%20de%20la%20data/)<br>
Conception et présentation du portfolio de compétences acquises au cours de la formation.
